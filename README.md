# TGThesis

B.A. thesis (Public Policy / CIR), Leja Ejury.
**Question:** How do periods of political or economic crisis change government reliance on privately held data, and do these changes persist after the crisis ends?

## Structure
```
data/
  raw/             original downloads (not tracked by git)
  processed/       cleaned data made by scripts
scripts/           code: cleaning, analysis, figures
visualizations/    figures and tables
drafts/            thesis drafts
```

## Everyday workflow
1. Edit drafts, add data and scripts.
2. Commit and push your work:
   ```
   git add -A
   git commit -m "what changed"
   git push
   ```
