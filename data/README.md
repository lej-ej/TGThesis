# Data

- `raw/`: original downloads, never edited by hand. **Not tracked by git** (too large); note here where each file came from so it can be re-downloaded.
- `processed/`: cleaned data made by scripts in `scripts/`. Tracked by git, but GitHub rejects any single file over 100 MB, so keep very large outputs out (add them to `.gitignore`).
